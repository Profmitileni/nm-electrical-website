NM ELECTRICAL AND SERVICES — WEBSITE SOURCE
=============================================

Files
-----
index.html   Main website markup
styles.css   Responsive styling
script.js    Mobile navigation, current year, and WhatsApp quote form

Preview locally
---------------
1. Extract the ZIP file.
2. Open index.html in a current browser.
3. Internet access is not required for the design itself; WhatsApp and phone links need connectivity.

Publish on a website
--------------------
Upload all three files to the same directory on a web host, keeping their filenames.
The site is a static HTML/CSS/JavaScript website and is not a WordPress theme or plugin.

WordPress note
--------------
WordPress.com free plans may not allow uploading a custom theme or using arbitrary plugins.
The full coded site is easiest to host on a static host with a free tier, or on self-hosted WordPress
where you can install a custom theme. Embedding the entire site in a Custom HTML block may be
restricted and is not equivalent to installing a complete website theme.

Before launch
-------------
- Confirm the business owner authorises use of the company name and phone numbers.
- Confirm service offerings and qualifications, especially for regulated electrical, solar, and CoC work.
- Replace the project gallery placeholders with genuine photos shared with permission.
- Test all phone and WhatsApp links.
- Add the correct business location, email, privacy details, and any required legal information.

WhatsApp
--------
The quote form opens WhatsApp with a prefilled message to 071 513 0004.
The visitor must press Send in WhatsApp. This static site does not store form data.
